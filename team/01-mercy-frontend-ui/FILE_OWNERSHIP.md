# File Ownership

- **Own:** `frontend/`, `tests/frontend/`, frontend screenshots.
- **Modify after coordination:** API contract comments and frontend sections of docs.
- **Approval required:** database schema, backend routes, SQL and AI service code without owner approval.
- Generated files, dependency locks, and shared contracts require owner review.
- When two branches touch the same file, agree on one editor and cherry-pick or rebase after review.
