# File Ownership

- **Own:** `database/design/`, `docs/data-dictionary.md`, ERD and normalization.
- **Modify after coordination:** schema review notes.
- **Approval required:** executable production SQL or migrations without Sashtika/Yasmin review.
- Generated files, dependency locks, and shared contracts require owner review.
- When two branches touch the same file, agree on one editor and cherry-pick or rebase after review.
