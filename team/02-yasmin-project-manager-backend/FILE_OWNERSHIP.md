# File Ownership

- **Own:** root/planning documents, `backend/`, integration tests and release coordination.
- **Modify after coordination:** all modules during reviewed integration.
- **Approval required:** another member's active feature without discussion; history rewriting on shared branches.
- Generated files, dependency locks, and shared contracts require owner review.
- When two branches touch the same file, agree on one editor and cherry-pick or rebase after review.
