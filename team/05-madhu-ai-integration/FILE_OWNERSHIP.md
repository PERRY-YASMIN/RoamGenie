# File Ownership

- **Own:** `ai/`, AI schemas/services/tests and AI contract docs.
- **Modify after coordination:** backend AI adapter/router with Yasmin review.
- **Approval required:** raw database credentials, direct database writes, unrelated backend/frontend code.
- Generated files, dependency locks, and shared contracts require owner review.
- When two branches touch the same file, agree on one editor and cherry-pick or rebase after review.
