# File Ownership

- **Own:** `database/schema`, `seeds`, `queries`, `views`, `functions`, `procedures`, `triggers`, `indexes`, `transactions`, `reports`, `tests`.
- **Modify after coordination:** data dictionary corrections through review.
- **Approval required:** ER model or ORM migrations without Samyuktha/Yasmin approval.
- Generated files, dependency locks, and shared contracts require owner review.
- When two branches touch the same file, agree on one editor and cherry-pick or rebase after review.
