# File Ownership

- **Own:** assigned catalogue API support, API tests/docs, `presentation/`, demo evidence.
- **Modify after coordination:** backend catalogue routers/schemas assigned in an issue.
- **Approval required:** auth/core trip logic, schema, or another member's slides without review.
- Generated files, dependency locks, and shared contracts require owner review.
- When two branches touch the same file, agree on one editor and cherry-pick or rebase after review.
