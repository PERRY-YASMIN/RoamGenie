## 1. Executive Summary

RoamGenie v1.0.0 is an intelligent, relational database-backed travel itinerary planner and budget optimization platform developed for the Semester 5 DBMS course curriculum. The application centralizes normalized travel catalogue data across 500 destinations (6,000 accommodations, 6,000 restaurants, 2,517 attractions, and 6,000 transport routes), accepts multi-dimensional trip constraints, and generates structured day-wise itineraries with itemized budget allocations, deficit warnings, weather context, dynamic packing checklists, manual catalogue entity swapping, and multi-turn AI travel assistant chat.

All 7 engineering remediation milestones (M1–M7) have been completed and verified with 100% test coverage across backend, database integrity, security, and frontend single-page architecture.

1. **User Authentication & Profile Management:**
   - Secure registration, login, logout, and token expiration handling.
   - Argon2id password hashing and expiring JWT bearer tokens.
   - User profile customization with normalized travel styles, dietary preferences, and activity tags.
2. **Master Travel Catalogue Explorer:**
   - 500 global destinations across continents with average daily expense baselines.
   - 6,000 accommodations with pricing tiers, addresses, and rating metrics.
   - 6,000 dining venues with cuisines and average per-person costs.
   - 2,517 sightseeing attractions with categories, entry fees, and opening hours.
   - 6,000 inter-city transit routes with provider metadata, transit modes, and estimated tariffs.
3. **Trip Planning & Deterministic Itinerary Scheduler:**
   - 5-step parameters wizard (destination, origin, dates, travellers, total budget, activity preferences, AI toggle).
   - Validation ensuring $\text{end\_date} \ge \text{start\_date}$, duration $\le 31$ days, positive budget, and 1–50 travellers.
   - Deterministic day-wise schedule allocation mapping catalogue entities to start times and meal slots.
4. **Budget Calculation, Optimization & Manual Item Swapping:**
   - Itemized 5-category budget calculation (accommodation, transportation, food, attractions, contingency).
   - Deficit detection visualizer with colored progress bar and explicit alerts.
   - Interactive timeline item replacement modal allowing users to swap hotels, restaurants, sights, or transit with catalogue alternatives.
   - Atomic budget recalculation and transactional rollback safety on invalid replacements.
5. **Weather Forecasting & Dynamic Packing Checklist:**
   - Open-Meteo live geocoded forecast integration with current summary, temperature, and WMO weather codes.
   - Dynamic packing list generator with interactive checklist items (add, toggle packed, delete).
6. **Grounded AI Travel Copilot:**
   - Multi-turn assistant grounded in trip parameters, budget allocations, forecast data, packing items, and destination catalogue.
   - Multi-provider architecture (Gemini, OpenAI, Groq) with deterministic offline fallback (`MockLLMProvider`).
   - IDOR-protected multi-turn conversation persistence in PostgreSQL.
7. **Saved Trip Persistence & Hydration:**
   - Atomic multi-table database persistence across `trips`, `itineraries`, `itinerary_days`, `itinerary_items`, and `budget_allocations`.
   - Saved trip reload (`/plan?tripId=X`) hydrates exact persisted itinerary from PostgreSQL with zero duplicate database rows.
   - Zero-persistence guest preview mode for unauthenticated visitors.
8. **DBMS Showcase & SQL Playground:**
   - Interactive demonstration interface executing 18 analytical SQL benchmark queries (Q01–Q18) live against PostgreSQL.
   - PL/pgSQL trigger (`trg_trip_audit`) capturing all trip mutations into `trip_audit` JSONB logs.
   - Read-only custom SQL playground secured with admin RBAC, blocking DDL/DML, multi-statement injection, and sensitive credential tables.

## 5. Non-Blocking Limitations & Future Scope

### Non-Blocking Limitations (Documented Scope Boundaries)
1. **Single Base Currency:** All monetary values are computed in INR (₹).
2. **Fixed Catalogue Scope:** Catalogue dataset covers 500 cities and 21,017 entities; adding new cities requires database seeding.
3. **Mock Default for Offline / Evaluation:** Default AI configuration uses `MockLLMProvider` for deterministic, offline testing; live Gemini/OpenAI keys can be supplied via `.env`.

### Future Scope (Post-v1.0.0 Enhancements)
1. **PDF / Ticket Export:** Automated PDF generation of day-wise itineraries and booking vouchers.
2. **Calendar Sync:** Export scheduled activities as `.ics` calendar events (Google Calendar / Apple Calendar).
3. **Interactive Map Visualizer:** Leaflet/Mapbox integration for visual route mapping between scheduled itinerary coordinates.
4. **Live Booking Gateways:** Direct booking API integrations with airline, hotel, and rail reservation platforms.
