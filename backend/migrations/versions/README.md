# Alembic Revisions

No application revision is generated automatically in this planning starter because SQLAlchemy entity models are a Milestone 1/2 deliverable. After schema v1 approval and model implementation, run `alembic revision --autogenerate -m "create initial travel schema"`.

Review every operation against `database/design`, `database/schema/001_schema.sql`, and the DDL ownership plan before applying it. The reviewed initial migration must recreate application tables on an empty Supabase development project; never accept an empty autogenerated revision.
